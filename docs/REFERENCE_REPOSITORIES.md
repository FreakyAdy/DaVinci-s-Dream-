## 1. `Shannon-Labs/davinci-codex`
**URL:** https://github.com/Shannon-Labs/davinci-codex

### What it is
A React web application that displays Leonardo da Vinci''s Codex Atlanticus pages as an interactive digital archive. It fetches high-resolution scans from a CDN, overlays annotation layers, and provides a pan/zoom viewer.

### Relevant Patterns
- **Folio ID schema:** Uses `CA-{sheet}-{recto/verso}` identifiers
- **Manuscript image CDN:** Serves .jpg at 1200x900
- **Historical metadata shape:** `{ id, name, period, codex, folio, description, tags[] }`

## 2. `JiazeCai/flappy_v2`
**URL:** https://github.com/JiazeCai/flappy_v2

### What it is
Small Python Gymnasium environment for a 2D flapping-wing agent. Discrete action space, gravity+lift model, trains DQN via stable-baselines3.

### Key Differences From Our Implementation
- Discrete action space vs our continuous Box([-1,1]^3)
- Simplified lift/gravity only vs our full quasi-steady aerodynamics
- No wind field vs our configurable wind_x, wind_y
- No 3D visualization vs our Three.js WebGL kinematic rig

### License
No LICENSE file. **No code copied.** Pattern reference only.

## 3. `TH3SOLO1ST/ornithopter_cfd`
**URL:** https://github.com/TH3SOLO1ST/ornithopter_cfd

### What it is
MATLAB/Python CFD notebook using vortex-lattice method for flapping ornithopter aerodynamic coefficients.

### Relevant Cross-References
- CL values 0.8-1.4 at typical advance ratios — we use CL_max=1.2
- Flapping thrust formula matches our dynamics.py
- Stall limit at ~18deg matches our alpha_stall=0.32 rad

### License
MIT License. **No code copied.** Numerical cross-reference only.

## 4. `srishtyraghav/Application-of-DeepRL-for-Aircraft-control`
**URL:** https://github.com/srishtyraghav/Application-of-DeepRL-for-Aircraft-control

### What it is
Final-year project applying PPO/DDPG from SB3 to fixed-wing aircraft in JSBSim.

### Patterns Referenced
- PPO hyperparameters: lr=3e-4, n_steps=2048, batch_size=64, gamma=0.99 (SB3 defaults, confirmed appropriate for flight)
- Observation normalization strategy
- Two-controller baseline vs PPO comparison architecture

## 5. `Gor-Ren/gym-jsbsim`
**URL:** https://github.com/Gor-Ren/gym-jsbsim

### What it is
Gymnasium wrapper around JSBSim 6-DOF aircraft simulator.

### Patterns Referenced
- 10-dimensional observation structure: [altitude, u, v, theta, q, sin(phi), cos(phi), target_dist, wind_x, wind_y]
- sin/cos encoding for periodic flap phase to avoid discontinuities
- Episode termination conditions (altitude OOB, time limit, target arrival)

### License
MIT License. **No code copied.** Observation design pattern only.
