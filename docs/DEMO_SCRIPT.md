# Demonstration Script (60–90 Seconds)
## Da Vinci's Dream: Interactive Renaissance Invention Laboratory

### Target Audience
Evaluators, researchers, engineers, and historical science enthusiasts.

---

### Step-by-Step Walkthrough

| Timestamp | Screen / Area | Action | Spoken / Visual Narrative | Expected Result |
| :--- | :--- | :--- | :--- | :--- |
| **0:00 - 0:15** | **Discover Landing** | Land on the hero view; inspect the Renaissance codex blueprint. | *"Welcome to Da Vinci's Dream — an interactive laboratory bridging Renaissance invention codices with modern computational physics and reinforcement learning."* | Dramatic parchment blueprint, illuminated workshop aesthetic, clear call-to-action to enter lab. |
| **0:15 - 0:30** | **Invention Archive & Capabilities** | Click "Archive"; view machines. Click "Codex Flight Ornithopter" then "Inspect". | *"Leonardo envisioned machines centuries before the materials existed to fly them. Here we see our machine registry with honest capability tracking."* | Archive grid displays machines. Capabilities clearly marked (Drawing, 3D, Physics, RL). |
| **0:30 - 0:45** | **Sketch Explorer** | Click "Sketch Explorer"; upload an invention sketch or view sample automaton. | *"In the Sketch Explorer, users can upload historical drawings or blueprints. The system matches capabilities and provides honest diagnostics if a machine is unsupported."* | Instant preview of uploaded sketch, notes and category tagging, capability diagnostic badge. |
| **0:45 - 1:15** | **Flight Laboratory Simulation** | Enter "Flight Lab". Launch simulation in **Baseline Mode**. Toggle **3D Wireframe** and **Side View**. Observe wing flapping and live telemetry. | *"In the Flight Laboratory, we simulate the 1505 flapping ornithopter using a 2D aerodynamic engine. Watch the 3D model's wings articulate in real-time with lift and thrust."* | 3D ornithopter flaps wings in sync with physics; altitude, airspeed, and trajectory plot update dynamically. |
| **1:15 - 1:30** | **Reinforcement Learning & Benchmark** | Switch to **RL Policy** mode or click **Run Evaluation Benchmark**. Observe comparative metrics. | *"We can train an intelligent PPO agent or compare our trained neural policy against the rule-based baseline under identical wind conditions."* | Evaluation panel shows genuine comparative metrics (Success rate, distance, energy expenditure). |

---

### Contingency Procedures
- If backend service is connecting: Frontend shows polite connecting spinner with offline mode simulation fallback.
- If PPO model is not yet trained: UI displays "Policy Untrained" with one-click "Train PPO Agent" button and allows instantaneous Baseline controller flight.
